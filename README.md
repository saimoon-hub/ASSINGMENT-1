# ASSIGNMENT 1 – DATA STRUCTURES USING C

## Introduction
This repository contains four C programming assignments based on different types of Queue data structures. All programs are implemented using arrays.

## Programs Included

### 1. Linear Queue
Implementation of a linear queue using an array with insertion, deletion, and display operations.

### 2. Circular Queue
Implementation of a circular queue of size 5 with insertion and deletion operations.

### 3. Deque (Double Ended Queue)
Implementation of a deque using an array. Insertion and deletion can be performed from both front and rear.

### 4. Priority Queue
Implementation of a priority queue using an array. Elements are inserted with priorities, and the element with the highest priority is deleted first.
